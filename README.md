# daily

每天一条的 AI 资讯日报索引仓库。

- 每天北京时间 09:00 由 GitHub Actions 先建好当天的页面，保证当天一定有提交、页面一定存在；
- 每天 13:00、21:00 再核查两次，来源站出刊晚了也能当天补上，前两天没补上的也会顺带回查；
- 来源站当天断更时，页面保留为“待更新”占位，不会因此断了这个仓库的每日记录。

内容说明：本仓库只放索引和我自己写的精简概括，不全文转载来源站的日报。
原文版权归 AGI HUNT 所有，每页都附原文链接，详情请看原文。

- 来源站：https://agihunt.info/daily/
- 每页：`daily/YYYY-MM-DD.md`
- 汇总：`log.md`
